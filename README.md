# ollama-tui

Tokyo Dark front-end for **Ollama**, with **web UI** and **terminal UI** in one install.
Self-hosted, zero native build, runs on DietPi, Raspberry Pi 4, Linux amd64/arm64.

## One-command install

```bash
curl -L https://github.com/psyc-exe/ollama-tui/releases/latest/download/ollama-tui.tar.gz \
  | tar xz && ./install.sh
```

Or via the inline installer:
```bash
curl -L https://raw.githubusercontent.com/psyc-exe/ollama-tui/main/installer/install-online.sh | bash
```

Non-interactive flags:
```bash
./install.sh --mode both --port 8080 --no-ollama --prefix /usr/local
```
- `--mode web|tui|both` (default: both)
- `--port N` (default 8080)
- `--no-ollama` skip ollama download
- `--prefix DIR` install root (default `/usr/local`)

## Install behavior

- Detects arch (amd64 / arm64).
- If `ollama` is **already installed** -> skips download, only installs front-end.
- If `ollama` is **absent** and `--no-ollama` not set -> downloads matching official release.
- Installs chosen UI(s) into `$PREFIX/bin/`:
  - `ollama-tui-web` - web UI server
  - `ollama-tui`     - terminal UI client

## Run

```bash
# Web UI (phone / TV / desktop browser)
PORT=8080 OLLAMA_HOST=http://127.0.0.1:11434 ollama-tui-web

# Terminal UI (over SSH, headless)
ollama-tui
OLLAMA_MODEL=rpi-qwen:latest ollama-tui
```

## Web UI features

- Tokyo Dark theme, responsive 5" -> 32" TV.
- Streaming chat via `/api/chat` SSE.
- Context compression (`/api/chat` emits `ctx` event with ratio).
- Per-turn regenerate, model picker (Ctrl+/).
- Exports: JSON, Markdown, compact summary.
- `/search <q>` web-search injection.
- Optional Telegram bridge (lazy, disabled by default).
- Optional Ollama self-update (dry-run first).

## TUI features

- Full-screen panel layout (header / scrollable log / input / status).
- Streaming output into log, auto-scroll.
- Slash commands: `/model <name>`, `/models`, `/clear`, `/exit`.
- Mouse toggle: `Ctrl+Alt+T` (off by default on Termux).
- Controls only: `ESC HOME UP DOWN END PGUP PGDN TAB`, plus `Ctrl+Alt+{C,M,T}`.

## Files

```
ollama-tui/
  server.js              web HTTP+SSE
  compressor.js          headroom-based context compression
  ollama-update.js       amd64/arm64 self-update (lazy)
  telegram.js            optional telegram bridge (lazy)
  public/index.html      web UI
  public/app.js          web UI logic
  tui-full.js            terminal UI (blessed)
  build-new.js           web bundle generator
  install.sh             interactive / flag-driven installer
  installer/
    install-online.sh    one-command curl|bash wrapper
```

`dist/` is build output, generated by `build-new.js` (see below).

## Build from source

```bash
node build-new.js
cp tui-full.js dist/ollama-tui-tui.js
tar czf release/ollama-tui-v0.1.0.tar.gz \
  install.sh dist node_modules package.json README.md
```
